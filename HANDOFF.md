# Playlist Builder - Handoff

This repository contains curated DJ tracklists, timestamps, and release-status
notes. The public tree is intentionally limited to portable playlist data and
public reference material.

## Repository structure

- `Classic_House_Vinyl_Set_Tracklist.md` - classic house vinyl set notes
- `WORSHIP/` - WORSHIP and related artist/live-set tracklists
- `WORSHIP/YOUTUBE_CATALOGUE.md` - public playlist reference catalogue

## Editorial conventions

- Track order and timestamps are preserved from the source where available.
- `Released` and `Unreleased` markers reflect the reference material used when
  each list was prepared.
- Unidentified tracks remain marked as unidentified rather than being guessed.
- Source links are retained with the relevant playlist or setlist.

## Privacy boundary

Local network details, device paths, library share credentials/configuration,
generated reports, and workstation-specific design notes are not part of this
public repository. The `.gitignore` also protects common local-only artifacts
from accidental publication.
